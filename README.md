## 👩🏻‍💻 DevRoutine  
- 평소 캘린더와 투두리스트를 자주 활용하면서, 두 기능을 하나의 서비스로 자연스럽게 통합해보고 싶다는 생각을 하게 되었습니다. 특히 일정 관리와 업무 관리가 분리돼 있을 때 불편함을 자주 느꼈고, 이를 해결하기 위해 **‘업무(Task)’와 ‘일정(Schedule)’을 한 화면에서 효율적으로 관리할 수 있는 풀스택 프로젝트**를 기획하게 되었습니다.이번 프로젝트는 직접 실사용할 목적이 크기 때문에, UI 디자인부터 기능 흐름까지 모두 **바이브 코딩으로 구현**하며 사용자 경험을 세심하게 고민하고 있습니다.
